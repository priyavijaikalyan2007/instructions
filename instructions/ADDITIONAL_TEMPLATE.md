# Additional instruction template

This file becomes the consuming project's local refinement file when copied to ADDITIONAL.md.
The project profile identifies its path. AGENTS.md requires reading that configured file.
Project facts belong in PROJECT.md. Reusable engineering rules belong in their generic subject guides.

## Project-specific instructions

Record each local instruction with its component scope and reason.
Identify an exception explicitly when it changes a shared rule. Preserve the user's current instructions.

## Emerging lessons

Record a new lesson with the problem, applicable scope, evidence, and current local rule.
For reusable lessons, propose an update to the generic guide that owns the subject.
Remove project names and private details from the proposed generic instruction.
After adoption, remove redundant local wording while retaining any project-specific nuance.

## Pending shared updates

Record the proposed shared guide, review status, and remaining local difference.
